# Dino Arcade - Chrome Dino Game para Raspberry Pi

Juego estilo arcade del dinosaurio de Chrome para Raspberry Pi Zero 2W.
Incluye sonidos y gráficos.

## Estructura del proyecto

- `src/` - Código fuente (.cpp)
- `include/` - Archivos de cabecera (.h)
- `bin/` - Ejecutable generado
- `obj/` - Objetos intermedios

## Compilación

```bash
make
